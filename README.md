# シフト希望メモ

店長宛てのシフト希望メモの文面をブラウザで作る、自分専用の静的サイトです（ビルド不要・外部ライブラリなし）。

## 開き方
Finder で `index.html` をダブルクリックするか、ターミナルで次を実行します。

```bash
open index.html
```

## 機能
- **対象週の選択**：「今週」「来週」ボタン、または日付を選ぶと、その日を含む週（日曜始まり）が対象になります。日曜の日付が「M/D」で表示されます。
- **曜日ごとの希望（日〜土）**：日付と曜日、「不可」チェック、開始・終了時刻（8:00〜22:00、30分単位）。「不可」にすると時刻は選べなくなります。
  - 初期値：日13:00・月12:00・火16:00・水13:00・木19:00・金19:00・土は不可、終了は全日22:00
- **週の勤務回数の上限**：1〜7回（既定5回）
- **Googleカレンダー**：対象週の自分の予定を画面に表示します（PCは週表示、スマホは予定リスト）。
  - 初回は「カレンダーの設定」にカレンダーID（ふつうは自分の Gmail アドレス）を入れます。
  - Google の埋め込み表示を使うので、そのブラウザで Google にログインしている必要があります。予定が出ないときは、ブラウザがサードパーティ Cookie をブロックしていないか確かめてください（Safari は既定でブロックするため、Chrome がおすすめ）。
- **自動保存**：入力はブラウザ（localStorage）に保存され、次に開いたときに復元されます。
- **文面（自動更新）**：入力を変えるたびに、下の欄の文面がすぐ作り直されます。
- **送信**：OS の共有画面（LINE・メール・メモなど）が開きます。共有画面に対応していないブラウザでは、文面をクリップボードにコピーします。

## 文面の例
```
以下、11/16以降のシフトです。

(日) 13:00から22:00
(月) 12:00から22:00
(火) 16:00から22:00
(水) 13:00から22:00
(木) 19:00から22:00
(金) 19:00から22:00
(土) 不可

一日の勤務時間は6時間以下。一週間の勤務回数は5回以下でお願いします。
```
