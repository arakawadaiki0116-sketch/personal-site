# シフト希望メモ

店長宛てのシフト希望メモの文面をブラウザで作る、自分専用の静的サイトです（ビルド不要・外部ライブラリなし）。

## 開き方
Finder で `index.html` をダブルクリックするか、ターミナルで次を実行します。

```bash
open index.html
```

### スマホで開く
GitHub Pages で公開しています（URLを知っていれば誰でも開けます。入力した内容とカレンダーIDは、それぞれのブラウザの中にだけ保存されます）。

https://arakawadaiki0116-sketch.github.io/personal-site/

iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」でアプリのように使えます。`main` に push すると、1〜2分で反映されます。

## 機能
- **対象週**：いつも「来週」（次の日曜〜土曜）。画面の上に「11/15(日)〜11/21(土)」のように出ます。
- **ログイン**：決めた Google アカウントでログインしたときだけ、来週の予定が出て、入力内容がほかの端末と共有されます。ほかのアカウントは通りません。
  - ログインは端末（ブラウザ）ごとに最初の1回だけ。そのあと180日はログインしたままです。
  - ログインしていなくても、メッセージ作りはその端末の中だけで使えます。
  - ログアウトは一番下の「ログインの設定」から。
- **予定**：Googleカレンダーの来週の予定を「9:00–12:10 大学 講義」のように始まりと終わりの時刻つきで出します（2日分ほどの高さで、中をスクロール）。繰り返しの予定も出ます。曜日の行を触ると、上の予定がその日まで送られます。
- **希望時間（日〜土）**：開始・終了時刻はダイヤル式（上下にスワイプ。PCはホイールか矢印キー）。8:00〜22:00、30分単位。「不可」を押すとその日のダイヤルは止まります。
  - 初期値：日13:00・月12:00・火16:00・水13:00・木19:00・金19:00・土は不可、終了は全日22:00
- **週の勤務回数の上限**：1〜7回（既定5回）
- **自動保存と共有**：入力はこのブラウザの中に保存され、ログイン中は Cloudflare にも保存されて、ほかの端末で開いても同じ内容が出ます（最後に変えた内容が残ります）。
- **メッセージ（自動更新）**：入力を変えるたびに、メッセージがすぐ作り直されます。
- **送信**：OS の共有画面（LINE・メール・メモなど）が開きます。共有画面に対応していないブラウザでは、メッセージをコピーします。

## メッセージの例
```
以下、11/16以降のシフトです。

(日) 13:00から22:00
(月) 12:00から22:00
(火) 16:00から22:00
(水) 13:00から22:00
(木) 19:00から22:00
(金) 19:00から22:00
(土) 不可

一日の勤務時間は6時間以下。一週間の勤務回数は5回以下でお願いします。
```

## 中継役（worker/）
Cloudflare Workers で動く小さなプログラムです（https://shift-calendar.arakawadaiki0116.workers.dev ）。Google ログインの確認、来週の予定の読み出し、入力内容の保存（Cloudflare KV）を受け持ちます。

| 名前 | 種類 | 中身 |
| --- | --- | --- |
| `GOOGLE_CLIENT_ID` | wrangler.toml | Google Cloud の OAuth クライアントID（公開してよい値） |
| `ALLOWED_EMAIL` | 秘密の設定 | ログインを許すメールアドレス |
| `SESSION_SECRET` | 秘密の設定 | 通行証の署名に使う鍵。変えると全端末がログアウトします |
| `ICS_URLS` | 秘密の設定 | Googleカレンダーの「iCal形式の非公開URL」。複数なら空白で区切る |

```bash
cd worker
npm install
npm test                                  # 繰り返し予定の展開・ログイン確認の試験
npx wrangler secret put ICS_URLS          # 非公開URLを入れる・変える
npx wrangler deploy                       # 中継役を載せ直す（wrangler.toml を変えたとき）
```

- 全端末をログアウトさせたいとき：`openssl rand -base64 48 | npx wrangler secret put SESSION_SECRET`
- 非公開URLが漏れたと思ったら、Googleカレンダーの設定で「リセット」して、新しいURLを入れ直してください。
