# シフト希望メモ

店長宛てのシフト希望メモの文面をブラウザで作る、自分専用の静的サイトです（ビルド不要・外部ライブラリなし）。

## 開き方
Finder で `index.html` をダブルクリックするか、ターミナルで次を実行します。

```bash
open index.html
```

### スマホで開く
GitHub Pages で公開しています（URLを知っていれば誰でも開けます。入力した内容とカレンダーIDは、それぞれのブラウザの中にだけ保存されます）。

https://arakawadaiki0116-sketch.github.io/personal-site/

iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」でアプリのように使えます。`main` に push すると、1〜2分で反映されます。

## 機能
- **対象週**：いつも「来週」（次の日曜〜土曜）。画面の上に「11/15(日)〜11/21(土)」のように出ます。
- **予定**：Googleカレンダーの来週の予定を、画面の上に2日分ほどの高さで表示します。
  - 初回は、一番下の「カレンダーの設定」にカレンダーID（ふつうは自分の Gmail アドレス）を入れます。入れるまでは予定の欄は出ません。
  - Google の埋め込み表示を使うので、そのブラウザで Google にログインしている必要があります。Safari はサードパーティ Cookie を止めるため、予定が出ないことがあります（Chrome なら出やすい）。
  - 埋め込み表示の制限で、予定は開始時刻だけが出ます（終了時刻は出ません）。
- **希望時間（日〜土）**：開始・終了時刻はダイヤル式（上下にスワイプ。PCはホイールか矢印キー）。8:00〜22:00、30分単位。「不可」を押すとその日のダイヤルは止まります。
  - 初期値：日13:00・月12:00・火16:00・水13:00・木19:00・金19:00・土は不可、終了は全日22:00
- **週の勤務回数の上限**：1〜7回（既定5回）
- **自動保存**：入力はこのブラウザの中（localStorage）に保存され、次に開いたときもそのまま残ります。Safari とホーム画面のアイコンは保存場所が別なので、使う方を決めておくと確実です。
- **メッセージ（自動更新）**：入力を変えるたびに、メッセージがすぐ作り直されます。
- **送信**：OS の共有画面（LINE・メール・メモなど）が開きます。共有画面に対応していないブラウザでは、メッセージをコピーします。

## メッセージの例
```
以下、11/16以降のシフトです。

(日) 13:00から22:00
(月) 12:00から22:00
(火) 16:00から22:00
(水) 13:00から22:00
(木) 19:00から22:00
(金) 19:00から22:00
(土) 不可

一日の勤務時間は6時間以下。一週間の勤務回数は5回以下でお願いします。
```
